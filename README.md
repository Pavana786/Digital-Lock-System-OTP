# Digital Lock System with OTP Verification

## Overview
This project implements a secure Digital Lock System using Two-Factor Authentication (2FA). The design combines password verification and OTP authentication using a Finite State Machine (FSM) implemented in Verilog.

## Objectives
* Design a secure digital lock using OTP verification.
* Implement FSM-based control logic.
* Verify functionality using simulation and testbench development.
* Demonstrate two-factor authentication concepts in digital design.

## Features
* Password authentication
* OTP verification
* FSM-based architecture
* Secure lock/unlock mechanism
* Verilog implementation
* EDA Playground simulation

## FSM States
1. LOCKED
2. PWD_OK
3. UNLOCKED

## Development Flow
* Verilog Design
* FSM Implementation
* Testbench Creation
* Simulation
* Verification and Analysis

## Results
The lock remains secure when incorrect passwords or OTPs are entered and unlocks only after successful completion of the correct authentication sequence.
